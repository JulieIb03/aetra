# AETRA

Sitio estático de medicina de longevidad, construido en HTML5, CSS3 y JavaScript Vanilla ES6+ sobre el Design System aprobado.

## Ver el sitio

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Home: `http://127.0.0.1:8765/` · Design System: `http://127.0.0.1:8765/design-system.html`

Once páginas, navegación responsive, motion progresivo y recorrido de intereses. No necesita instalación ni compilación. Sin backend, reservas o envío de datos. El contenido no proporcionado está marcado como pendiente.

- Implementación y contenido pendiente: `docs/frontend.md`
- Verificación del sitio: `docs/frontend-qa.md`
- Sistema aprobado: `docs/design-system.md`
- Procedencia de imágenes: `docs/asset-provenance.md`
- Verificación de la guía original: `docs/qa.md`
